# OpenRecord v3.2.0 release notes

OpenRecord v3 is the production-workflow release: faster local editing, a more expressive visual stack, and portable automation without accounts or cloud dependencies.

## Highlights

- Edit by transcript, review local pause suggestions, create multiple non-destructive cuts, and keep every media/telemetry track synchronized through one time mapper.
- Generate smarter cursor-aware zooms, add timed cursor treatments, and use multi-select, copy/paste, duplicate, snapping, and keyboard editing.
- Add blur/pixelation, vector drawing, richer callouts, generic device frames, expanded webcam treatments, and local audio polish with preview/export parity.
- Start recordings from media-free project templates or save/import/export `.openrecordtemplate` files.
- Batch only the projects you select, keep different presets per job, continue after failures, and retry failed jobs.
- Import MP4/MOV/M4V recordings from an iPhone or other device without weakening desktop capture.
- Inspect, validate, export, or batch ordinary `.openrecord` bundles with `openrecord-cli`.

## Requirements

- macOS 15 or later
- Apple Silicon (`arm64`)

## Distribution note

The GitHub artifact is locally signed for integrity but is not Apple-notarized. macOS may require the usual explicit first-open approval for software downloaded outside the App Store.
